# Weather backdrops

Drop full-screen photographs here to replace the procedural gradient
backgrounds. `WeatherBackdrop` falls back to a gradient for any file that is
missing, so you can add them one at a time.

Expected filenames (all `.jpg`):

| File                | Shown when                          |
| ------------------- | ----------------------------------- |
| `clear_day.jpg`     | Clear sky, daytime                  |
| `clear_night.jpg`   | Clear sky, night                    |
| `partly_cloudy.jpg` | Mainly clear / partly cloudy, day   |
| `overcast.jpg`      | Overcast                            |
| `fog.jpg`           | Fog or rime fog                     |
| `rain.jpg`          | Drizzle, rain, or rain showers      |
| `snow.jpg`          | Snow, snow grains, or snow showers  |
| `storm.jpg`         | Thunderstorm                        |

Guidance: shoot or pick images that are **darker and lower-contrast toward
the top and bottom** — the scrim already darkens those bands for the status
bar and floating nav, and a busy bright edge fights the white type. Portrait
orientation, at least 1080x2400, is ideal.
